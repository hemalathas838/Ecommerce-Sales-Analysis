# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce sales dataset to understand sales performance, customer behavior, product categories, order status, and customer reviews.

The project was completed as part of a Data Analytics Internship using Python, SQL, and Power BI.

## Objectives

- Analyze total sales and revenue
- Analyze order and customer data
- Identify sales trends over time
- Analyze revenue by product category
- Analyze sales across different regions
- Understand customer review ratings
- Create an interactive Power BI dashboard

## Dataset

The project uses the Olist Brazilian E-Commerce Dataset.

The dataset contains information about:

- Orders
- Order Items
- Products
- Customers
- Reviews
- Product Category Translation

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- SQL
- Power BI
- Excel / Google Sheets
- GitHub

## Data Cleaning

The data was cleaned and prepared before analysis.

Main steps included:

- Handling missing values
- Combining relevant datasets
- Translating product categories
- Creating revenue-related fields
- Removing duplicate or unnecessary fields
- Preparing the final dataset for Power BI

## Power BI Dashboard

The dashboard contains the following key performance indicators:

- Total Revenue
- Total Orders
- Average Review Score
- Total Customers

### Dashboard Visualizations

- Monthly Sales Trend
- Revenue by Product Category
- Sales by Region
- Revenue by Order Status
- Review Score Distribution

## Key Results

- Total Revenue: 13.63M
- Total Orders: 96.478K
- Average Review Score: 4.08 / 5
- Total Customers: 96.478K

The analysis provides an overview of e-commerce sales performance and customer reviews. The Power BI dashboard makes it easier to explore important business metrics and identify patterns in sales and customer feedback.
